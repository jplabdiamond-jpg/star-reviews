コラム 管理画面を開く
How to use

集めた声を、サイトに載せる。

コピーして貼るだけ。色・レイアウト・枚数・自動スライドまで、管理画面から自由にカスタマイズできます。サイトが無くても公開URLで共有できます。

1全体の流れ

やることは3ステップだけです。

STEP 1声を集める

投稿フォームのリンクやQRを、LINE・メール・店頭で案内。匿名でも投稿できます。

STEP 2掲載する声を選ぶ

届いた声は「受信トレイ」に入ります。載せたい良い声だけ「掲載する」で承認。

STEP 3サイトに載せる

タグを1行貼る、または公開URLを共有。承認した声が自動で表示されます。

本文は編集できない設計です。いただいた声はそのまま掲載されるので、やらせ感なく安心して使えます。どれを載せる・載せないかは、あなたが選べます。

2載せ方は2つ

サイトがあるかどうかで選べます。両方使ってもOKです。

方法A

自分のサイトに埋め込む

タグを1行貼るだけ。サイトのデザインに溶け込みます。

  • WordPress・STUDIO・ペライチ・Shopify・素のHTMLなどで動作
  • サイトのCSSと干渉しない安全な作り（Shadow DOM）
  • 承認済みの声だけを自動表示
方法B

公開ページを共有する

サイトが無くてもOK。URLを配るだけ。

  • Instagram・LINE・名刺・Googleマップに貼れる
  • 検索に強い構造化データ入りの独立ページ
  • 有料プランなら独自URL（/wall/好きな名前）も設定可

3方法A：サイトに埋め込む

1
管理画面の「埋め込み」タブを開く

見た目を調整して「この設定を保存」すると、貼り付けコードが発行されます。

2
このタグをコピーして、サイトの載せたい場所に貼る

HTMLを貼れる場所ならどこでもOKです。

<script src="https://star-reviews.net/widget.js" data-token="pub_xxxxx" async></script>

pub_xxxxx の部分は、あなた専用のトークンに自動で入ります（管理画面でコピーしたタグをそのまま使えばOK）。

表示する位置を指定したいとき

表示したい場所に次のタグを置くと、そこに描画されます。置かない場合は、スクリプトを貼った直後に表示されます。

<div data-star-reviews></div>
どのサービスで使える？ HTMLタグを貼れるサービスならほぼ対応しています。
WordPressSTUDIOペライチShopifyWix素のHTMLReact / Next.js

4方法B：公開ページを共有する

サイトを持っていなくても、「埋め込み」タブに表示される公開URLをそのまま使えます。

https://star-reviews.net/wall/あなたの店名

このURLをInstagramのプロフィール・LINE・名刺・Googleマップのリンク欄などに貼るだけ。サーバー側で描画される独立ページなので、Google検索やSNSシェアでもきれいに表示されます。

覚えやすい独自URL（例：/wall/my-shop）は、Starter以上のプランで設定できます。あわせて、ページ下部の「star-reviews」表記も消せます（ホワイトラベル）。

5見た目をカスタマイズ

管理画面の「埋め込み」タブで調整して「この設定を保存」すると、サイト埋め込み（A）とホスト型ページ（B）の両方に反映されます。貼り替えは不要です。

テーマカラー★・マーカー・アバターの色。見本8色＋好きな色を指定できます。
並べ方グリッド / マソンリー（高さ自由）/ カルーセル（横スクロール）/ リスト / チップス
表示する枚数すべて、または 3・6・9・12・20枚。多すぎる時に絞れます。
自動スライドカルーセル選択時に、カードを自動で横送り（on/off）。
★マークの種類ゴールド・ハート・絵文字・数値表示など全10種。
カードの見せ方ライト（白カード）/ ミニマル（罫線）/ 引用 / ダーク。
星サマリー上部の「平均★と件数」の表示・非表示。
ライブプレビューを見ながら調整できます。気に入ったら「この設定を保存」を押してください。

個別に上書きしたいとき（上級者向け）

特定の1か所だけ見た目を変えたい場合は、タグに属性を足すと、その埋め込みだけ保存設定より優先されます。

<script src="https://star-reviews.net/widget.js" data-token="pub_xxxxx" data-layout="carousel" data-star="heart" data-theme="dark" async></script>
属性値
data-layoutgrid / masonry / carousel / list / chips
data-stargold / mono / emoji / heart / number / big / glow / shine / metal / mini
data-themelight / minimal / quote / dark
data-summaryoff で平均★サマリーを隠す
data-schemaoff で構造化データ(JSON-LD)の出力を止める

6Google検索に★を表示（SEO）

埋め込み・公開ページのどちらも、レビューの構造化データ（JSON-LD）を自動で出力します。これにより、Google検索の結果に★（リッチスニペット）が表示される対象になります。

※ 実際に表示されるかはGoogleの判断で、反映には数日かかることがあります。不要な場合は data-schema="off" を足してください。

7よくある質問

貼った後に新しい声が増えたら？
承認した声が自動で反映されます。タグの貼り直しは不要です。
声の内容は編集できますか？
本文は編集できない設計です。いただいた声をそのまま掲載します。どれを「掲載する／しない」かは選べます。
表示が崩れたりサイトのデザインに影響しませんか？
埋め込みはShadow DOMという仕組みで隔離されているため、サイト側のCSSと干渉しません。
写真や動画の声も載りますか？
はい。写真付き・動画付きの声も、埋め込み・公開ページの両方で表示されます（動画には日本語字幕も自動付与。形式により付かない場合があります）。
見た目を変えたら、貼り替えが必要？
不要です。保存した設定をA・B両方が読み込むので、管理画面で保存するだけで反映されます。
